# Workout History CSV Export

Workout History can export the active profile's currently visible result set as a UTF-8 CSV file.

## Source of exported rows

The export action uses the same in-memory `WorkoutHistoryFilter` result as the History list. It therefore preserves the active status, period/custom date range, workout, search and sort selections. Export does not reload or mutate session storage.

## CSV schema

The header is stable and ordered as follows:

`session_id,workout_id,workout_name,profile_id,profile_name,started_at,ended_at,status,active_duration_seconds,completed_steps,total_steps,estimated_calories,effort,note`

Timestamps are local ISO-8601 values. Optional calories, effort and note values are blank when absent. CSV fields containing commas, quotes or line breaks are quoted and embedded quotes are doubled.

## UX

The Workout History app bar exposes an `Export CSV` action. If the current filters return no sessions, no file is created and the user receives non-fatal feedback. Cancelling the save dialog leaves all data unchanged. Successful export reports the number of exported sessions.

Web export passes bytes directly to the file picker. Other supported platforms use the selected path and write the generated bytes there, matching the existing Health export pattern.
